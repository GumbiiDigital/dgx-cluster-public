# Public-Safe Edition Boundary

## What this edition keeps

This repository retains generalized engineering notes, scripts, and test outcomes that can be understood without the original environment. The technical records are historical and sanitized; they are not a live runbook for any particular cluster.

## What is excluded

The public-safe tree excludes live network addresses, hostnames, machine and controller identifiers, hardware identifiers, account names, local filesystem paths, raw inventories, and raw captures. Placeholder strings are intentionally non-operational.

## Using the scripts

Treat every script as a reviewable example. Create a private configuration for your own environment and independently verify every target before execution. Never add live topology values, secrets, captured traffic, or private inventory data to this repository.

## Historical limitation

Removing material from the current branch does not remove it from prior commits, existing clones, forks, caches, releases, or merged pull-request text. Any history rewrite would require a separately reviewed, explicitly authorized migration plan.
